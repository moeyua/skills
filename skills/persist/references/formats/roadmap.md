# Roadmap format — `ROADMAP.md`

The home for deferred / future items, so the other memory artifacts stay about the present. **record-only**: the maintainer decides what and whether; this file just files it by format.

## Sections

- A short intro line stating it's record-only.
- Items grouped by theme (e.g. by area or skill), each a flat one-liner: **`X — because Y`** (what's deferred/planned + why). One bullet per item.

## Source

What the maintainer has decided to defer or plan. Append when a new deferral is decided; remove an item once it lands. Don't add items the maintainer didn't decide — stop and ask.

## Boundary

**Record, don't judge.** No prioritization (no P0/P1, no ordering-as-ranking), no scheduling (no dates / sprints / timelines), no "is it worth it" verdict. The moment ROADMAP ranks or schedules, it's left record-only and become planning — which is out of scope.

# Design format — `DESIGN.md`

The project's UI design: interface, interaction, and visual conventions. Audience is developers and collaborating agents building or changing the UI. Only for projects with a UI — a pure library / CLI / backend doesn't need it.

## Sections

- **界面结构 / Interface structure** — screens / views / key components and how they're organized.
- **交互流程 / Interaction flows** — the main user flows, step by step.
- **视觉规范 / Visual conventions** — spacing, color, typography, component states — whatever rules the UI holds itself to.

## Source

The maintainer's stated design intent + design files / mockups. Don't invent visual rules the maintainer never set — stop and ask.

## Boundary

- Not technical architecture (that's `ARCHITECTURE.md`); not behavior contracts (that's `specs/`).
- No future / deferred design ideas — those go to `ROADMAP.md`.

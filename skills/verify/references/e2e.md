# End-to-end Method

Use the project's documented launch path or an existing project-specific run capability. Drive the smallest real user path that exercises the expectation and compare observed behavior with the stated result.

Choose tools appropriate to the surface: invoke a CLI, call a running service, drive a browser or desktop app, or use a small existing library harness. Observe logs, visible state, outputs, and screenshots only when they contribute evidence.

Do not edit source or configuration to make the app launch. A missing dependency, startup failure, blocked login, or unavailable environment is an observed limitation and must be reported accurately.

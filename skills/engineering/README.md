# Engineering skills

Development, software architecture, testing, and engineering project maintenance.

| Skill                             | Outcome                                                                                                    |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [explore](./explore/SKILL.md)     | Read-only project/module understanding; fixed Overview before scoped depth.                                |
| [shape](./shape/SKILL.md)         | Intent and key design clarified through answerable questions.                                              |
| [plan](./plan/SKILL.md)           | Local plans, problem-oriented Issues, or pairs, with one audit and authorized corrections.                 |
| [debug](./debug/SKILL.md)         | Cause investigation from expected versus actual behavior, with evidence and explicit unknowns.             |
| [implement](./implement/SKILL.md) | An authorized working change with proportional proof and accurate durable truth.                           |
| [review](./review/SKILL.md)       | Evidence-backed findings on designs, planning artifacts, or changes.                                       |
| [verify](./verify/SKILL.md)       | A scoped verdict on whether the claimed outcome has sufficient evidence; formal acceptance when requested. |
| [docs](./docs/SKILL.md)           | Established truth recorded in the six-type catalog or a named project document.                            |
| [publish](./publish/SKILL.md)     | Missing commit, push, and pull-request actions completed from current state.                               |
| [release](./release/SKILL.md)     | A confirmed release set, one complete metadata commit, tags, and Releases.                                 |
| [converge](./converge/SKILL.md)   | Idempotent catalog-wide alignment to current memory formats.                                               |
| [doctor](./doctor/SKILL.md)       | Read-only whole-project documentation drift and health audit.                                              |

See the [Resolver](../RESOLVER.md) for route distinctions and the [repository README](../../README.md) for installation and usage.

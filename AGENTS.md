# Agent instructions

This repo is the user's own skill set: their agent harness. Settle every change to a skill's content or the repo's structure with the user before editing.

Before adding or editing a skill, read [CONTRIBUTING.md](./CONTRIBUTING.md).

- Skills live in `skills/<category>/<name>/SKILL.md`; the directory name is the skill name.
- `pnpm check` formats, lints, and typechecks. `pnpm test` checks skill structure.
- Release rules are in [RELEASE.md](./RELEASE.md).
